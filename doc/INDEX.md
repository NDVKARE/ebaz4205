## Đường dẫn chạy lệnh

Các lệnh build trong tài liệu Ibex được chạy từ thư mục mã nguồn `vivado/ibex_min/` ở đầu dự án, không chạy từ `doc/vivado/ibex_min/`.

Các đường dẫn file trong sơ đồ mô tả cây mã nguồn; liên kết Markdown đã cập nhật theo vị trí tài liệu.
